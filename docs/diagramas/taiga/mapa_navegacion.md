# Mapa de navegación

**Páginas por rol**

Después de iniciar sesión, cada rol entra a su propia vista. **Salir** vuelve al inicio de sesión.

## Páginas

| Rol | Página | Ruta |
|---|---|---|
| Todos | Inicio de sesión | (sin hash) |
| Agente | Comunicados | #/comunicados |
| Agente | Levantar la mano | #/ayuda |
| Supervisor | Cola de ayuda | #/cola |
| Supervisor | Presencia | #/presencia |
| Supervisor | Nuevo comunicado | #/comunicados/nuevo |
| Supervisor | Comunicados publicados (detalle desplegable) | #/comunicados |
| Administrador | Listado, agregar y editar usuarios | #/usuarios · #/usuarios/nuevo · #/usuarios/{id} |
| Administrador | Listado, agregar y editar campañas | #/campanas · #/campanas/nueva · #/campanas/{id} |
| Administrador | Listado, agregar y editar equipos | #/equipos · #/equipos/nuevo · #/equipos/{id} |
